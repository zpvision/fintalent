# FinTalent Academy — программа и материалы

Документ описывает Этап A. Учебная комната, зачисления, публикация версий и
прогресс реализованы в [Этапе B](ACADEMY_STAGE_B.md).
Тесты и сдача/проверка работ — [Этап C](ACADEMY_STAGE_C.md).

Вход: **Профиль → Мои курсы → Открыть Академию**,
`/profile/courses/{course_id}/academy`. Нужны пользовательская сессия владельца
и доступ к курсам через существующие настройки админки. Административная сессия
сама по себе не предоставляет права изменять учебные материалы автора.

## Данные и версии

Миграция `078_academy.sql` подключена через `academy_module.go` и
`prepareDatabase()`, после курсов и тестов. Она повторяема.

- `academy_course_programs`: одна независимая рабочая программа курса, источник,
  ревизия. Изменения не меняют статус, ревизию, программу или цену лендинга.
- `academy_modules`, `academy_lessons`, `academy_lesson_blocks`: нормализованная
  редактируемая структура. ID проверяются вместе с program_id и key.
  Стабильные key сохраняют логическую идентичность при фиксации версии.
- `academy_program_versions`: неизменяемые структурированные снимки программы,
  уникальные по ревизии. Триггер запрещает UPDATE/DELETE. Черновик продолжает
  редактироваться отдельно. Будущий поток должен ссылаться на ID версии, а
  прогресс — на зачисление, версию и key урока. Снимок не открывает доступ ученикам.
- `academy_media_assets`, `academy_asset_links`: метаданные закрытых файлов и
  разрешённые связи с уроками/модулями. При дублировании создаются новые ключи
  сущностей и дополнительные связи с неизменяемыми файлами. Физические файлы
  не удаляются при редактировании программы; материалы снимков сохраняются.

Копирование лендинга — явная транзакция под блокировкой курса, с собственными ID
и key. Повторный запрос возвращает существующую программу. Автосинхронизации нет.
Ревизия программы проверяется под блокировкой перед каждой записью; устаревший
клиент получает 409. Команды и автосохранение используют один writer.

Потоки, зачисления, сдача работ, прогресс и события сейчас не создаются.
Расписаний/дат открытия на уроках нет. Правила завершения — конфигурация будущей
учебной комнаты; интерфейс явно это обозначает. Тест привязывается к конкретному
`test_versions.id` теста автора; новый движок тестов не создаётся.

## API

Префикс `/api/academy/courses/{course_id}`. Владение и доступ к модулю проверяются
на backend при каждом запросе, включая скачивание.

| Метод и путь | Назначение |
| --- | --- |
| GET `/` | Курс, программа или null, доступные версии тестов, снимки |
| GET `/program` | Дерево рабочей программы |
| POST `/program` | `{source: "empty" | "landing"}`, идемпотентная инициализация |
| PUT `/program` | Полное дерево с revision; атомарное сохранение/сортировка |
| POST `/actions` | `{revision,type,key,target?,index?,module?,lesson?,block?}` |
| GET/POST `/modules` | Модули / создание модуля |
| GET/PUT/DELETE `/modules/{key}` | Чтение / обновление / удаление модуля |
| GET/POST `/modules/{key}/lessons` | Уроки / добавление урока |
| GET/PUT/DELETE `/lessons/{key}` | Урок с содержимым / настройки / удаление |
| GET/POST `/lessons/{key}/blocks` | Блоки / добавление блока |
| GET/PUT/DELETE `/blocks/{key}` | Блок / обновление / удаление |
| POST `/{modules|lessons|blocks}/{key}/move` | Атомарное перемещение |
| POST `/{modules|lessons|blocks}/{key}/duplicate` | Дублирование с новыми ID/key |
| GET `/preview/{lesson_key}` | Предпросмотр, включая черновики |
| POST `/versions` | `{revision}`, фиксация снимка; повтор идемпотентен |
| GET `/assets` | Метаданные закрытых файлов программы |
| POST `/assets` | Multipart entity_key, file; сущность должна быть сохранена |
| GET/HEAD `/assets/{id}` | Авторизованная выдача; ?download=1 для скачивания |
| DELETE `/assets/{id}` | Пометка неиспользуемого файла; ссылки снимков защищены |

Команды: `module.create/update/delete/move/duplicate`,
`lesson.create/update/delete/move/duplicate`, `block.create/update/delete/move/duplicate`.
В ресурсных alias-маршрутах тип и key берутся из URL; тело — тот же контракт
команды с revision и module/lesson/block. Для lesson.move target — key модуля.
Для block.create key — урок, index — место вставки.

## Редактор и сохранение

React: `frontend/src/pages/academy/`. Общий `LessonRenderer` предназначен также
для будущей учебной комнаты. Используется существующий Editor.js bundle с
ограниченным набором текстовых инструментов. Сервер очищает inline-разметку
через bluemonday; renderer преобразует разрешённые теги в React-узлы, без вставки
произвольного HTML. Обычный редактор публикаций сохраняет прежний набор инструментов.

Автосохранение через 900 мс, последовательная очередь запросов. Поздний ответ не
заменяет новые правки: объединяются только ID и revision. Перед сменой урока,
командой, upload и предпросмотром ожидается сохранение текста и программы.
«Сохранено» появляется после ответа сервера. При ошибке правки остаются в памяти
и sessionStorage вкладки; доступны повтор, экспорт JSON и загрузка серверной
версии. Восстановление резервной копии требует выбора автора.

## Файлы и развёртывание

`ACADEMY_STORAGE_DIR` — закрытый каталог; по умолчанию `.local-data/academy`.
Запрещён внутри static, не коммитится, не должен раздаваться Nginx и должен
иметь постоянный volume и резервное копирование вместе с PostgreSQL.
Пользователю процесса Go нужны права записи; новые каталог/файлы — 0700/0600.
Имена хранения случайные, без пользовательских путей.

Один файл до **20 МБ**: JPEG, PNG, GIF, WebP, PDF, DOCX, XLSX, PPTX, ZIP, TXT, CSV.
Проверяется содержимое; OOXML проверяется как архив, макросы запрещены. HTML,
SVG и исполняемые файлы не принимаются. ZIP не распаковывается сервером.
Выдача использует Content-Disposition, nosniff, CSP sandbox, private/no-store.
Замена/удаление блока отвязывает материал, не уничтожая файлы прошлых версий.

Конфигурации Nginx в репозитории нет, production-лимит не проверен. Для upload
location требуется client_max_body_size **21m** или больше с учётом multipart;
внешний proxy также должен пропускать этот размер. Приложение не меняет proxy.

Большие видео не загружаются. Поддержаны YouTube/Vimeo/Rutube и HTTPS MP4/WebM,
название/длительность/постер. Внешние ссылки не защищают платные видео: следующему
этапу нужны video provider, временные токены и HLS с сохранением общего renderer.

Обновление: npm run build, сборка/перезапуск Go. Миграции применяются при старте.
Учебные материалы не попадают в публичный API курсов.

## Проверки

- `go test ./internal/academy ./internal/courses`, `go test ./...`.
- Изолированная облачная PostgreSQL: `RUN_COURSES_DB_TESTS=1 go test . -run '^TestCoursesIsolatedPostgres$' -count=1 -timeout=10m`.
  Требует DATABASE_URL, работает только в собственной временной схеме.
- `npm run build`; `node scripts/academy-browser-check.cjs` — actual React build,
  headless Edge, тестовые API без production/DB. EDGE_PATH задаёт путь Chromium,
  если стандартный Edge недоступен. Скриншоты сохраняются в OS temp.
